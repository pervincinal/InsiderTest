  - **Recommendation: do not pool.** Script is 9–15 % of the frame and GC 0.2 %; pooling sim/particle objects would win well under 1 ms of a 117 ms throttled frame. The cost is draw calls / fill rate in the dynamic layer (terrain and roads are already cached in `render/terrain.ts`).
