# Tower Clash — launch checklist

## 0. How to release build 6 (1.0.0) — stakeholder steps in order (written 2026-09-25 on HEAD `4b7738f`)

1. **Create the tag.** GitHub → repository → *Releases* → *Draft a new release* → *Choose a tag* → type `tower-clash-v1.0.0` → *Create new tag on publish* → *Target* → tab *Recent Commits* → `4b7738f` (2026-09-24, head of `claude/tower-war-game-plan-weqwpb`, carries 1.0.0 / build 6; any later docs-only commit on that branch is the same build). Title `Tower Clash 1.0.0`, body = the EN "What's new" block of `RELEASE_NOTES.md` v1.0.0. *Publish release*.
   → Team: the Producer marks V3 / T1 done here and PUB-9 in `docs/BACKLOG.md`; the daily report announces day L (`POST_LAUNCH.md` §1). The game does not change.
2. **Enable GitHub Pages.** *Settings → Pages → Build and deployment → Source: GitHub Actions* → save. Then *Actions → tower-clash-pages → Run workflow* on `claude/tower-war-game-plan-weqwpb` (or wait for the next push touching `tower-clash/`). If the `github-pages` environment is protected, allow that branch (`docs/DEPLOY.md`).
   → Team: QA checks `https://pervincinal.github.io/InsiderTest/`, `…/privacy.html` and `…/support.html` with `curl -I` + one Playwright smoke (T2); the Publisher drops the "active once Pages is enabled" notes from the README and the listing (W6).
3. **Send the two values** for the `[developer e-mail]` / `[developer name / address]` placeholders (4 in `tower-clash/public/privacy.html`, 2 in `support.html`, listing G18) in the report thread → Team: the Publisher edits the files, the next push republishes them (T3).
4. **Store accounts and signing keys** — §2 G1–G4, §3 A1–A5, §5 secrets, §6 MZ1–MZ2 / MZ7 / MZ13 → Team: the Mobile Engineer adds the `bundleRelease` (G5) and signed-archive (A6 / A8) jobs the day the secrets exist; the Tech Artist re-renders the store screenshots on build 6 (G10 / A11) — store assets, not part of the tag.
5. **Device test** — install the CI debug APK on a phone (README "Android APK from CI") and paste what you see in the report thread → Team: QA + Mobile Engineer close T8 / MM-1 and file bugs.
6. **Then** T6–T11 in §8: closed test (14 days), TestFlight, sandbox purchases, store forms, soft-launch countries — every row says whose turn it is.
