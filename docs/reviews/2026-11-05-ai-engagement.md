## 1. What the flag does

`EnemyAiOptions.opponentAwareness` (`src/ai/personalities.ts`) is a **per-match option object**, not a level field, not a sim modifier, not a save: `enemyCommands(state, enemy, rng, memory?, options?)`, `runAiTick(state, rng, memories?, options?)` and `runHeadless(level, seed, player, { ai })` take it; the game client (`src/ui/play.ts`) and every script pass nothing, so the shipped game and every playtest row run exactly today's enemies. With it on:

- `attack` (`tactics.ts`, `AttackConfig.front`) gives each hostile target a *front bias* in ms. A target with a bias is planned on a horizon of `planMs + bias` and ranked as if it fell `bias` sooner (`score − bias`). The enemies' `front` returns the bias for the **player's** towers and 0 for greys and rivals — "who the opponent is" is the player's colour, which a human sees too.
- The bias is per personality at aggression 1, `FRONT_BIAS_S` = rusher **20 s**, opportunist **10 s**, turtle **5 s** (the rusher is the one meant to come for the player), scaled like the horizon by `0.5 + 0.5 × a`, and **zero below `DEFENCE_MIN_AGGRESSION` = 0.35** — a tutorial enemy that never defends does not hunt either. Without that gate the first run of the day took level 2 (rusher 0.2) from 20/20 to 0/20 for the naive line and level 5 from 20/20 to 8/20 under `tie desc`; with it, bands 1–8 are byte-identical on, off and without the option.
- Nothing else moves: the aggression gate, `maintain` (`MIN_ATTACK_MS` 5 s, the hopeless rule, retreat, the standoff release), `defend`, the opportunist's under-fire preference (60 s, it still outranks the 10 s bias), `stack`, `supply`, the parity races and the hold rules. An enemy still answers an attacker and still takes a free grey when the player's tower is out of every reach.
- `frontBiasS` on the option overrides the three numbers (measurement sweeps only).

Proof that off = today: `tests/ai/opponentAwareness.test.ts` (11 tests: the bias numbers, the gate, rusher / turtle / opportunist decision rules on fixtures, `enemyCommands` identical with no options / `{}` / off, level 49 seed 1 identical under the naive line with the option off and different with it on); `npm run playtest -- --seeds 3` before and after the change differs only in its `perf:` line; `scripts/reclock.ts --seeds 20` dry run prints today's list (CHANGED 3, 6, 7, 8, 12, 25, 41, 42; tie floor held back 10, 18, 21, 23, 32 — as on Day 45 / AUD-A9).
